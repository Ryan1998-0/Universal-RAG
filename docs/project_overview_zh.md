# 泛用 RAG 工作台專案說明

## 專案定位

這是一套可替換知識庫、模型與檢索設定的本機優先 RAG 架構。核心程式不預先知道文件主題，只有在使用者選擇知識庫與文件後，才依該次查詢範圍進行檢索。

IFRS 17、勞動法規及公開科學資料只用於驗證不同資料型態，不是系統的固定領域。

## 問答流程

```text
使用者問題
  -> 判斷是否需要檢索
     -> 一般問答或日期時間工具
     -> 查詢改寫
        -> 文件與知識庫範圍過濾
        -> BM25 + Embedding
        -> RRF 融合 + Rerank
        -> 證據品質檢查
        -> 模型根據證據生成回答與引用
```

## 文件流程

```text
PDF / 圖片 / DOCX / TXT / Markdown / JSON
  -> 格式與大小驗證
  -> 解析或 OCR
  -> 標準化與父子分塊
  -> Embedding 與索引持久化
  -> 加入知識庫
  -> 使用者選擇本次查詢範圍
```

## 泛用化設計

- `default` 是空白的泛用知識庫，可直接加入任意支援格式的文件。
- `profiles/<名稱>` 只保存可選的領域設定、別名與查詢擴展。
- 模型由 `RAG_MODEL` 與 `RAG_ALLOWED_MODELS` 設定，不綁定 Qwen。
- Profile、文件、資料夾與來源範圍由執行期資料決定。
- 日期時間、一般回答與文件限定回答使用不同系統提示，避免互相污染。
- 正式版以 PostgreSQL、Qdrant、物件儲存與背景 Worker 支援多租戶及非同步匯入。

## 目前限制

- GitHub Pages 是靜態介面，不含模型與文件處理服務。
- 正式部署仍需在目標 Linux 環境完成 OIDC、負載、安全、備份與回滾驗證。
- 不同領域若有專用縮寫，可選擇建立 Profile 擴展；不建立也能使用通用混合檢索。
