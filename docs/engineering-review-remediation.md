[PR #1 CI run 36232310768](https://github.com/Ryan1998-0/Universal-RAG/actions/runs/36232310768) passed. | 12 | Existing Qdrant collection schema compatibility | CI passed; staging bootstrap pending | Bootstrap previously accepted an existing collection based only on `dense` size, although the production adapter writes and queries `bm25`. [PR #1 CI run 36232601504](https://github.com/Ryan1998-0/Universal-RAG/actions/runs/36232601504) passed; an existing incompatible collection now fails during bootstrap rather than later traffic. |
| 13 | Replacement upload hides the active document from retrieval | CI passed; staging answer check pending | Completing a replacement upload changes `DocumentRecord.status` to `processing` before a new index is published. Searchable source IDs now depend on active index membership, matching `current_version_id` and an undeleted document; the replacement workflow status no longer hides the still-active version. [PR #1 CI run 36232727318](https://github.com/Ryan1998-0/Universal-RAG/actions/runs/36232727318) passed. |
| 14 | Cold backup and restore omit the production Compose environment | CI passed; host restore drill pending | The runbook uses `.env.production` for all Compose operations, but the scripts called `docker compose` without it, so required interpolation can fail during stop/restart. Backup archives are streamed to the caller-owned directory; success is reported only after Compose restarts. Restore requires an exact four-file SHA-256 manifest and matching project metadata before stopping. [PR #1 CI run 36233001725](https://github.com/Ryan1998-0/Universal-RAG/actions/runs/36233001725) passed; a non-root host backup and isolated restore drill remain required. |
